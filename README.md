# PulseFlow — SaaS Landing Page

A responsive, interactive SaaS landing page built for the Sankar Group Front-End Development Internship assignment.

## Technologies Used
- **HTML5:** Semantic sectioning (`header`, `nav`, `section`, `footer`)
- **Tailwind CSS (CDN):** Responsive grid layouts, spacing, and mobile-first styling
- **Vanilla JavaScript (ES6+):** Mobile navigation drawer, interactive sprint preview switcher, Monthly/Annual pricing toggle, plan pre-selection, and form validation

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any web browser (Chrome, Safari, Firefox) or run using the VS Code **Live Server** extension.
